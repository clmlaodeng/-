# 解方程练习生成器

这是一个本地可运行的“解方程专项出题”网页工具，定位不是泛泛按难度出题，而是把小学高年级到初一衔接范围内的解方程题型拆细，让老师能按年级、题面特征、易错点、课堂说法和例题快速找到要练的题。

## 核心能力

- 覆盖 13 大专项、58 个细分题型。
- 支持按关键词搜索，例如“五年级上册”“两边都有 x”“未知数作除数”“去分母漏乘”“小数点错位”。
- 支持直接粘贴例题定位题型，例如 `3(x+2)=20`、`30%x=12`。
- 提供“按老师需求找题”“题型全景图”“找题词典”“题型档案”，突出垂直题型库优势。
- 一键生成学生版和答案解析版，适合直接打印。
- 没有 AI Key 也能完整使用本地题型库；配置 AI Key 后可使用 AI 增强，失败时自动回退本地生成。

## 当前覆盖

- 方程概念与等式性质：判断是不是方程、判断方程的解、等式性质、数量关系列方程。
- 一步方程：加法、减法、乘法、除法。
- 未知数特殊位置：未知数作减数、作除数，几 x 作减数、作除数。
- 两步方程：加减两步、乘加乘减、先除后乘、能算的先算。
- 括号整体：括号作整体、括号前有减号、括号整体除法、括号内含系数。
- 合并同类项：同类项相加、相减、小数系数合并。
- 两边都有 x：基础型、含常数型、含减号型，尽量避免小学生不友好的负系数题面。
- 小数 / 分数：小数系数、分数系数、小数混合运算。
- 百分数 / 比例：百分数方程、比例式、按比例分配。
- 含分母 / 去分母：含 x/a、两边含分母、去分母漏乘诊断。
- 一元一次方程综合：去括号、移项、去分母、系数化 1。
- 检验与易错诊断：解后检验、漏做等式另一边、移项符号错误、去括号错误、小数点错位等。
- 列方程应用题：和倍、差倍、单价总价、周长、行程、追及、顺逆水、年龄、工程、分配等。

## 启动方式

推荐双击：

```text
启动解方程练习生成器.bat
```

或者在当前目录运行：

```powershell
npm start
```

默认打开：

```text
http://localhost:3107
```

如果 `3107` 被占用，服务会自动换到下一个可用端口，并在窗口里打印实际地址。

## 可选 AI 配置

OpenAI：

```powershell
$env:OPENAI_API_KEY="你的 Key"
npm start
```

DeepSeek：

```powershell
$env:DEEPSEEK_API_KEY="你的 Key"
npm start
```

不配置 Key 时，页面会显示“本地规则可用”，仍然可以完整生成练习。

## 验证

```powershell
npm test
```

测试会检查题型库、搜索、生成数量、答案代回、AI 回退、本地接口、页面资源和打印样式。

## 适合试用的方式

1. 打开网页后先看“按老师需求找题”和“找题词典”。
2. 搜一个课堂说法，例如“两边都有 x”“去括号变号”“未知数作除数”。
3. 选择细分题型或专题包。
4. 设置题目数量，点击“生成练习”。
5. 检查学生版和答案解析版，确认后点击“打印练习”。
