# 解方程练习生成器 MVP

本项目是一个本地可运行的解方程出题网页。它的定位不是泛泛按难度出题，而是做“解方程专项题型库”：把小学高年级到初一衔接范围内的解方程题型拆细，让用户能按专项分类、细分题型和训练重点直接找到要练的内容。

没有 AI Key 也能用本地专项题型库生成题目；配置 OpenAI 或 DeepSeek Key 后，可以勾选“使用 AI 增强”。

页面支持直接搜索题型。用户可以输入“方程的解”“等式性质”“除数是 x”“去括号”“应用题”“错因”“小数”等关键词，快速定位对应专项。

首页还提供“题型全景图”，直接展示所有专项分类和题型数量，让用户先看到覆盖范围，再进入生成。

## 当前覆盖

- 方程概念与等式性质：判断是不是方程、判断方程的解、等式性质选择、根据数量关系列方程
- 一步方程：加、减、乘、除
- 未知数特殊位置：未知数作减数、除数、小数除以未知数
- 两步方程：加减两步、乘加乘减、先除后乘、能算的先算
- 括号整体：括号作整体、括号前有减号、括号整体除法、括号内含系数
- 合并同类项：相加、相减、小数系数合并
- 两边都有 x：基础型、含常数型、带减号型
- 小数 / 分数：小数系数、分数系数、小数混合运算
- 检验与易错诊断：解并检验、等式两边同操作
- 列方程应用题：和倍、差倍、单价总价、几何周长、行程初步
- 错因诊断：漏做等式另一边、移项符号错误、去括号错误

## 核心优势

- 不是只按难度粗分，而是按解方程真实薄弱点拆分。
- 用户不用知道分类名称，可以通过关键词搜索定位题型。
- 用户也可以通过题型全景图浏览完整覆盖范围。
- 每道题都带训练重点；应用题带列式，错因诊断带错误过程和错误点。

## 启动

```powershell
npm start
```

打开：

```text
http://localhost:3107
```

如果 `3107` 已被占用，启动命令会自动换到下一个可用端口，并在终端里打印实际地址。

## 可选 AI 配置

OpenAI：

```powershell
$env:OPENAI_API_KEY="你的 Key"
npm start
```

DeepSeek：

```powershell
$env:DEEPSEEK_API_KEY="你的 Key"
npm start
```

没有 Key 时，页面会显示“本地规则可用”，仍然可以完整生成练习。

## 验证

```powershell
npm test
```

测试会检查三档难度生成、答案代回成立、AI 失败回退、本地接口、页面资源和打印样式。
